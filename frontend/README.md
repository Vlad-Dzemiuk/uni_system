# Портал довідок (Next.js 14 + TS + Tailwind + Shadcn-style UI)

## Запуск
```bash
npm i
npm run dev
```

## Демо-логіка
- Вхід тільки через Google (мок).
- Роль для демо обирається на сторінці входу.
- Дані мокаються у `lib/mockData.ts` та зберігаються у localStorage.

## Деканат
- /dean/certificates — список довідок (створення/редагування/видалення)
- /dean/orders — обробка заявок (фільтри, пагінація, схвалення/відхилення/скасування)
